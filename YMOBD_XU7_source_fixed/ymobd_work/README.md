# YMOBD XU7 — اصلاحات ایمنی اتصال و تشخیص

این پروژه Android/Kotlin/Jetpack Compose است. حالت واقعی از ابتدا انتخاب می‌شود و دادهٔ شبیه‌سازی فقط با فعال‌کردن دستی شبیه‌ساز در رابط کاربری تولید می‌شود.

## تغییرات این نسخه
- اصلاح مقداردهی اولیهٔ ELM327: فرمان‌ها روی سوکت واقعی اجرا می‌شوند حتی وقتی وضعیت هنوز `Connecting` است؛ شکست `ATE0` دیگر به موفقیت کاذب تبدیل نمی‌شود.
- سریال‌سازی فرمان‌ها با `Mutex` برای جلوگیری از تداخل درخواست‌ها.
- تشخیص قطع سوکت، timeout و پاسخ بدون prompt؛ ثبت فرمان/پاسخ و خطا در ترمینال برنامه.
- بررسی پاسخ مثبت ECU به `0100` قبل از اعلام ارتباط موفق با ECU.
- پاک‌کردن DTC فقط پس از پاسخ مثبت `44` تأیید می‌شود.
- تبدیل صحیح بایت‌های استاندارد DTC به قالب‌هایی مانند `P0115`.
- Routine IDهای اختصاصی تأییدنشده حذف شده‌اند و تنظیمات ویژه تا شناسایی دقیق ECU غیرفعال می‌مانند.
- صفحهٔ خطاها دیگر فهرست خالی را به‌عنوان سالم‌بودن قطعی خودرو معرفی نمی‌کند.

## ساخت
پیش‌نیازها: Android Studio، JDK سازگار با Gradle پروژه، Android SDK و دسترسی به مخازن Google/Maven.

پوشهٔ `ymobd_work` را در Android Studio باز کنید و اجازه دهید Gradle همگام‌سازی شود. سپس از منوی Build گزینهٔ Build APK(s) را اجرا کنید.

در ZIP منبع اصلی، فایل‌های Gradle Wrapper (`gradlew`, `gradlew.bat`, `gradle-wrapper.jar`) وجود نداشتند؛ بنابراین ساخت خودکار در این محیط قابل اجرا نبود. APK در این خروجی ساخته نشده است.

## محدودیت آزمون
اتصال واقعی، پاسخ ECU، پارامترهای زنده و DTCها نیاز به دانگل و خودروی واقعی دارند و در این محیط قابل تأیید نبودند. برای فعال‌سازی تنظیمات BCM/ECU باید شناسهٔ دقیق ECU و مستند معتبر فرمان‌های همان نسخه فراهم شود. هیچ فرمان اختصاصی حدسی ارسال نمی‌شود.
